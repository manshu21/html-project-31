**_Node.js Basic Server_**

This is a basic Node.js server project created using the built-in `http` module.

**_What This Project Does_**

This server has three different routes:

- `/` → Home Page
- `/about` → About Page
- `/contact` → Contact Page

**_How to Run_**

1. Make sure Node.js is installed.
2. Open the terminal in the project folder.
3. Run:

```bash
node server.js
```

4. Open the following URLs in a browser:

```text
http://localhost:3000/
http://localhost:3000/about
http://localhost:3000/contact
```

**_Technologies Used_**

- Node.js
- HTTP module
